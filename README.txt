🌕 中秋賞月 Moon Watch HK · V0.2

這是 Open-Meteo 天氣資料版本。

## 檔案
- index.html：網站頁面
- styles.css：手機版夜空 UI
- app.js：Open-Meteo 天氣資料、示範月亮資料及位置按鈕

## 現階段
- Weather：Open-Meteo
- 香港預設位置：22.3193, 114.1694
- 取得逐小時氣溫、雲量、降雨機率及能見度
- 初步計算「賞月指數」

目前月亮、月相、月出/月落及方位仍是示範資料。
